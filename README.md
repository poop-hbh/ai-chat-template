# 🤖 AI Chat Template

Простой шаблон публичного сайта с чатом и заготовкой под подключение ИИ.
Всё в одном файле — `app.py`. Без фронтенд-фреймворков, без сложной структуры.

## Что внутри

- **FastAPI** — бэкенд
- **HTML + CSS + JS** — фронт (вшит прямо в Python)
- **Заглушка ИИ** — сейчас бот повторяет сообщения, но готов к подключению настоящей LLM
- **Защита**: rate limiting, лимит длины сообщения, таймаут, CORS
- **/health эндпоинт** — для деплоя на Render / Railway

## Как запустить

    pip install fastapi uvicorn
    python app.py

Открыть: http://127.0.0.1:8000

## Как подключить настоящий ИИ

В файле `app.py` найди функцию `chat()`. Там есть блок:

    # --- ЗАГЛУШКА ---
    reply = f"Ты написал: «{user_text}». Я пока заглушка, но скоро стану умным."

Замени этот блок на вызов любого LLM API (Groq, OpenAI, OpenRouter, Ollama).
Логика простая: пользователь шлёт текст → сервер идёт в LLM → возвращает ответ.
